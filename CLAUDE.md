# times-tables

Issue tracker for this repo is GitHub Issues. Per-repo configuration for the engineering skills lives under `docs/agents/`, written by `/setup-matt-pocock-skills`; until that has been run, follow this file. The wayfinder map is the issue labelled `wayfinder:map`; its tickets are that issue's sub-issues, and blocking uses GitHub's native "blocked by" relationship.

Public-facing content (README, issues, commits) carries no personal details about the learner, their school, or the competition.
