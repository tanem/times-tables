# times-tables

Issue tracker for this repo is GitHub Issues, not the local-markdown tracker described in the machine-wide tracker-conventions skill. The wayfinder map is the issue labelled `wayfinder:map`; its tickets are that issue's sub-issues, and blocking uses GitHub's native "blocked by" relationship.

Public-facing content (README, issues, commits) carries no personal details about the learner, their school, or the competition.
