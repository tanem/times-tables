# times-tables

The wayfinder map is the issue labelled `wayfinder:map`; its tickets are that issue's sub-issues, and blocking uses GitHub's native "blocked by" relationship.

Public-facing content (README, issues, commits) carries no personal details about the learner, their school, or the competition.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues, driven with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels, each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
